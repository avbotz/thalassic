# Thalassic

High-level ROS 2 software stack for AVBotz's Marlin V3 AUV.

The documentation is located at https://sw.avbotz.com ([source](https://github.com/avbotz/software-docs)).

## Quick start

```bash
git clone --recurse-submodules https://github.com/avbotz/thalassic.git
cd thalassic
scripts/install.sh

pixi run up                 # simulation
pixi shell                  # interactive shell with ROS 2 + workspace
```
